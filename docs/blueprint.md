# **App Name**: Pavel Ray - Full Stack Portfolio

## Core Features:

- Concise Bio: Display a concise bio highlighting 12+ years of full stack web development experience and freelancing expertise.
- Project Showcase: Showcase key projects with descriptions, tech stack details (React, Node, Next.js, JavaScript), and links to live demos or repositories, highlighting the WITS University network traffic dashboard.
- Tech Stack Display: List comprehensive tech stack proficiency with clear categorizations.
- Contact Form: Provide contact form to facilitate client and job oppurtunites.
- LinkedIn Integration: Link to LinkedIn profile (https://www.linkedin.com/in/pavelray/) for detailed professional background.
- Personalized Introductions: Use an AI-powered tool to provide suggestions for personalized introductory messages depending on the context of how they accessed the web page, such as someone reaching the website from LinkedIn or from another portfolio website.
- Responsive Design: Implement a visually appealing and responsive design optimized for various screen sizes.

## Style Guidelines:

- Primary color: Deep Blue (#30475E) to convey professionalism and trust.
- Background color: Light Gray (#F0F5F9) for a clean, modern backdrop that allows content to stand out.
- Accent color: Teal (#548CA8) to highlight key elements and calls to action.
- Body font: 'Inter', a sans-serif font for a clean and modern feel.
- Headline font: 'Space Grotesk', a sans-serif font for a bold, tech-forward look.
- Use a set of consistent icons for tech stack and skills, maintaining a modern, professional style.
- Employ a clean, grid-based layout with ample white space to ensure readability and visual appeal.
